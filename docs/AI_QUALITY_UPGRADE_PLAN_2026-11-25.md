- 스포츠 같은 소재가 현재 장르 목록에 없을 수 있다. 모든 요청을 하나의 장르로 강제 변환하지 않고, 장르·소재·분위기·맥락을 구분해 여러 검색 단서를 활용한다.
- 줄거리에 요청 단어가 그대로 없어도 의미상 적합할 수 있다. 인용 원문의 존재·ID·시간 같은 사실 검증과, 적합성에 대한 모델의 해석을 구분한다. 키워드 일치와 인용 존재만으로 이야기의 중심 소재/분위기를 증명했다고 평가하지 않는다.
- 기존에도 SQL 후보 검색→모델 선정의 골격은 있다. 새로 전부 재작성하기 전에 앞단의 엄격한 문자열 조건·장르 추론·후보 범위·줄거리 정보가 모델의 판단 기회를 제한하는지 평가한다.
- 실제 카탈로그 안의 작품만 추천한다. 없는 데이터는 모델 지식으로 보충하지 않는다. 예시 작품의 미확인 사실/유사성을 검증했다고 주장하지 않는다.
- 필수 조건을 임의로 완화하지 않는다. 후보가 없으면 데이터 부족·조건 충돌·모호함·제공자 오류를 구분하고 필요한 확인/대안을 제시한다.
- 사용자 인증·소유권·비공개 반응 보호·턴 예산·원자적 저장·기존 기능을 보존한다. 의미 검색/벡터 DB/모델 교체는 도입 자체를 목표로 삼지 않고 비교 평가로 결정한다.
