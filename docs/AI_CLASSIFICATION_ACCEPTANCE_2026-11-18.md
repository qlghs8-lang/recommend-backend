## 확인된 남은 문제

1. **복합 개인화 요청에서 명시적 유형 누락.** 12개 분류 시도 중 3회 constraints=[]로 영화 조건이 빠졌다. 서비스 반복 3에서도 같은 누락을 관찰했고, 두 작업/원문은 보존됐지만 추천 부분이 후보 없음 안내로 끝났다. 현재 무조건 포함해야 하는 명시 조건을 놓칠 수 있어 파싱 성공만으로 품질을 수용할 수 없다.
2. **‘새 영화’의 해석 변동.** 추가 12개 복합 분류 중 3회 MEDIA와 ORDER NEWER를 반환해 MEDIA만 기대한 정답과 달랐다. ‘안 본 새 작품’과 ‘최근 공개작’의 언어적 모호성이 있으므로 이 세 건을 확정적인 추출 오류와 동일시하지 않는다. 실제 서비스 반복 2에서는 NEWER가 적용되어 취향 점수보다 최신 정렬이 앞서는 결과가 나왔다. 의도 경계 검토 후 필요하면 새 버전의 정답에서 다루되 현재 점수를 소급 변경하지 않는다.
3. **맞는 분류 뒤의 빈 선택.** 서비스 반복 3의 shorter는 MEDIA/MOOD/90분 상한/공포 제외/ONLY_LAST/SHORTER_MOVIE를 올바르게 추출했고, 추천 제공자 호출까지 진행했지만 recommendations=[]를 반환했다. 이 턴에서 공개 참조가 없어 자동 검사는 실패했다. 이번 조건의 기존 추천은 90분 한 편뿐이므로 실제로 더 짧은 대안이 없다는 점도 설명해야 한다. 이를 분류 잘림 재발로 분류하지 않는다.
4. **자동 검사의 한계.** compound는 비공개 목록을 포함해 공개 참조가 의도적으로 비워진다. 기존 자동 검사는 작업 순서·저장만 검사해 반복 3의 추천 없음도 통과했다. 합성 원문 수동 검토로 이 유용성 문제를 별도 기록했다. ‘shorter’ 첫 두 번의 90분 재추천은 서버의 최소값 선택 정책과 맞지만 비교할 작품이 하나뿐인 경우의 안내는 일관되지 않다.
5. **원인 미확정 분류 실패.** 기존 61개의 13개 불일치와 두 잘못된 응답은 최초 계획이 없어 필드별 원인을 확정하지 못했다. 별도 진단 네 건 성공으로 전체 상세·참조 회귀가 없다고 선언하지 않는다.
