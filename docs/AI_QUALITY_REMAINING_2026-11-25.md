실제 D24에는 모델의 분류 경로와 답변을 그대로 기록하고 선택된 본인 반응/VIEW 작품, 좋아했던 장르 밖 선택 여부를 별도 syntheticPolicyReview로 남긴다. 선택0이면 합격으로 처리하지 않는다. 개인화 선택은 현재 제품의 서버 로컬 경로를 사용하므로 원래 요청을 임의의 모델 선정 문제로 바꾸지 않는다. 원본의 privateRowsRead=0은 실제 비공개 행을 읽지 않았다는 뜻이며, 별도 syntheticFixtureSeeded/합성 감사 기록을 함께 해석한다.

D22의 독립 추천2개는 현재 단일 추천 계약의 경계다. 이를 수집 데이터 부족으로 오판하거나 이번에 제품 계약/평가 정답을 바꾸지 않는다. 모든 하위 기능이 통과한다고 미리 예상하지 않으며 실제 실패/미실행은 그대로 보존한다.
